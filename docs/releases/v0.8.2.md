# v0.8.2 — 调度模式切换延迟状态通知

> 发布日期：2026-11-16
> 上一版本：[v0.8.1](./v0.8.1.md)

## 修复内容

- **随下一次实际模型步骤通知切换**：开关变化时仅记录状态，通过 `agent/pre-step` 附加通知，明确开启态使用 `delegate` / `orchestrate`、关闭态直接使用常规工具。切换本身不立即插入消息或额外启动回合。
- **合并连续切换**：每个主代理独立记录基线；下一步前多次切换仅通知最终状态，回到基线则取消待发通知。新建会话以当前状态为基线，代理销毁时清理记录。
- **保护通知投递边界**：委派子代理不接收通知；步骤被拒绝、被中止或首步无消息时不消费待发状态。先加载消息构造器再消费通知，加载失败时保留待发状态。

## 升级说明

本版本为功能增强与交互优化，无破坏性变更，无新增配置项。直接升级并重启客户端即可生效。
