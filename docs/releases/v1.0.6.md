# v1.0.6 · 会话派发与工具 schema token 优化

- **工具 schema token 优化**：精简 `delegate` 和 `orchestrate` 提供给模型的说明。在同一条原生工具请求上，使用 o200k_base 对两份声明计数，合计从 2,474 降至 1,757，节省 717 个 token（29%）。参数结构、必填项和路由覆盖规则保持兼容。实际开销随可用工具及会话配置而变化。
- **空会话切换 PTC**：在仅本会话的 Dispatch 设置写入期间发出首条消息，派发守卫会等待该会话写入结算，再按生效设置处理请求。
- **可选 Team 任务 ID**：`delegate` 和 `orchestrate` 都将空串或纯空白的 `team_task_id` 视为省略，方便在 Team 关闭时调用。
- **双语面板布局**：窄栏中的英文 `More` 与中文“更多”均固定在标题首行右侧，标签可自行换行。中英文分别通过五档宽度的浏览器验证，覆盖键盘和鼠标操作。
