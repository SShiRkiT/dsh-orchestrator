# v0.8.1 — 调度模式开关优化

> 发布日期：2026-11-16
> 上一版本：[v0.8.0](https://github.com/SShiRkiT/dsh-orchestrator/releases/tag/v0.8.0)
> 提交范围：`7e0ebca..efd4039`

## 修复内容

- **关闭态恢复直接执行**：关闭调度模式后，主代理工具列表移除 `delegate` / `orchestrate`，恢复 `read` / `write` / `edit` / `bash` 等常规工具，并撤除工具描述中的强制委派规则。
- **执行门禁与开关一致**：关闭态放行常规工具，同时拦截 `delegate` / `orchestrate`，包括通过 `run_code` 嵌套发起的派发调用，避免历史上下文继续触发委派。开启态继续按 `allowedTools` 白名单控制主代理权限。
- **统一读取开关状态**：工具列表、工具描述与执行门禁共用 `isDispatchEnabled(config)`，兼容普通布尔值和 volatile 引用；仅显式 `false` 表示关闭，配置缺失或读取异常时保持开启。

## 升级说明

本版本为缺陷修复，无破坏性变更，无配置项增删。直接升级并重启客户端即可；此前关闭开关但行为未生效的会话，将按新的工具列表与门禁规则运行。
