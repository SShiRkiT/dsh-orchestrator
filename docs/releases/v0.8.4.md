# v0.8.4 — 迁移为公开 scoped npm 包

> 发布日期：2026-11-17
> 上一版本：[v0.8.3](https://github.com/SShiRkiT/dsh-orchestrator/releases/tag/v0.8.3)

## 主要改动

- **迁移为公开 scoped npm 包**：`package.json` 中的包名由 `dsh-orchestrator` 变更为 `@sshirkit/dsh-orchestrator`，版本升至 `0.8.4`，移除 `private: true`，新增 `publishConfig`（`access: "public"`、`registry: "https://registry.npmjs.org/"`）。发布后支持直接通过 npm 安装，并供 Plugin Market 索引关联。
- **同步前后端注册与加载标识**：`cordis.patch.yml` 的 `name`、`lib/client.js` 的 bundle 注册 `id` 与 `lib/index.js` 的导出 `name` 统一为 `@sshirkit/dsh-orchestrator`，保证前后端配对加载；补丁中的 `id: orchestrator` 保持不变，既有配置命名空间不受影响。
- **完善依赖与宿主引擎声明**：将 `peerDependencies` 从 `"*"` 收敛为显式兼容范围：`@deepseek-ai/schemastery: ">=3.18.5 <4.0.0"`、`@deepseek-ai/dsh-tools: ">=0.2.2-rc.2 <0.2.3-0"`、`@deepseek-ai/dsh-llm: ">=0.2.2-rc.2 <0.2.3-0"`、`zod: "^4.6.6"`。通过 `peerDependenciesMeta` 将动态导入的 `@deepseek-ai/dsh-llm` 标为可选，并声明 `engines`（`node: ">=22"`、`dsh: ">=0.2.2-rc.2 <0.2.3-0"`）。
- **补全打包白名单与双语文档**：`package.json` 的 `files` 新增 `docs/images`，完整包含 README 引用的截图；同步更新 `README.md` 与 `README.en.md` 中的版本徽章、兼容表及 npm CLI 安装命令。

## 升级说明

**⚠️ 升级须知：从旧版（`dsh-orchestrator`）升级到 `v0.8.4`（`@sshirkit/dsh-orchestrator`）时，必须先在 DSH 中卸载原先安装的旧版插件，再安装新版插件，最后完全退出并重启 DSH。**

包名已从 `dsh-orchestrator` 变更为 `@sshirkit/dsh-orchestrator`。若未先卸载旧版就直接安装新版，两份插件会同时存在并争抢同一个 `id: orchestrator` 与工具声明。

**宿主要求**：DSH `>= 0.2.2-rc.2 < 0.2.3-0`，Node.js `>= 22`。已在 DSH `0.2.2-rc.3` 宿主规范核对与 362 项单元测试中验证；不兼容 DSH `0.2.2-rc.1` 及更早版本，暂时无法升级宿主的用户应保持插件 `v0.8.2`。

升级步骤：

1. 确认宿主版本满足要求，在 DSH 插件页**卸载原先安装的旧版插件**。
2. 选择以下一种方式安装新版，**不要同时安装两份**。

   npm 安装（npm 发布后可用）：

   ```bash
   dsh plugin --profile desktop add @sshirkit/dsh-orchestrator
   ```

   或从 GitHub 安装：

   ```bash
   dsh plugin --profile desktop add https://github.com/SShiRkiT/dsh-orchestrator
   ```

3. 安装完成后，**完全退出并重启 DSH**，使前后端插件重新加载。
