# v0.8.5 — 移除客户端计划按钮与会话阶段投影

> 发布日期：2026-11-18
> 上一版本：[v0.8.4](https://github.com/SShiRkiT/dsh-orchestrator/releases/tag/v0.8.4)

## 主要改动

- **移除客户端专属计划按钮**：删除 `PlanToggle`（「• 计划」按钮，`orchestrator-plan-toggle`）、圆点样式 `dot()`、22 项 `toggle.*` / `stage.*` 双语文案、`setPlanFor`（调用 `/plan` 与 `/plan off`）及 `'remote.commands'` 服务注入。完整保留右侧「调度模式」面板（`RoutePicker`）、共享样式 `baseStyle` / `onStyle` 及模型目录 `remote.session.modelCatalog()`；宿主原生 Plan Mode 不受影响。
- **移除失去唯一 UI 消费者的会话阶段投影**：删除 `lib/stage.js` 与 `test/stage.test.mjs`，移除 `lib/index.js` 中的 `stageProjection` 定义 / 注册及 `package.json` 的 `zod` peer 依赖。保留 `sessionProjections` 服务注入，巡检防重复通知 `hasPendingNotice()` 继续读取宿主 `'inbox'` 投影；`orchestrate` 编排参数 `stages` 不受影响。
- **同步术语、设计说明与调度面板截图**：更新 `CONTEXT.md`、`docs/adr/0002-declarative-orchestrate-instead-of-native-workflow.md`，并替换 README 引用的 `docs/images/dispatch-panel.png`，展示移除「• 计划」按钮后的调度面板。

## 升级说明

**不兼容变更边界**：客户端不再注入快捷「• 计划」按钮，后端不再输出 `orchestrator` 会话阶段投影。若有外部插件读取 `useProjection('orchestrator')`，需适配该投影已移除的变化。宿主原生 `/plan` 及所有核心调度、路由、门禁、写租约、`delegate` / `orchestrate` 与巡检功能保持不变。

**宿主要求与验证**：DSH `>= 0.2.2-rc.2 < 0.2.3-0`，Node.js `>= 22`。已通过 350 项单元测试及隔离 Web 实例（DSH `0.2.2-rc.3`）验收。

**⚠️ 从旧非 scoped 包 `dsh-orchestrator` 升级时，必须先在 DSH 中卸载旧版插件，再安装新版 `@sshirkit/dsh-orchestrator`，最后完全退出并重启 DSH。** 包名不同的两份插件会争抢同一个 `id: orchestrator` 与工具声明。从 `v0.8.4` 升级也建议卸载旧版后重新安装，或更新后完全退出并重启 DSH，使前后端插件重新加载。

升级步骤：

1. 确认宿主版本满足要求，在 DSH 插件页卸载旧版插件，或更新已安装的 scoped 包。
2. 选择以下一种方式安装新版，不要同时安装两份。

   npm 安装（对应版本发布至 npm 后可用）：

   ```bash
   dsh plugin --profile desktop add @sshirkit/dsh-orchestrator
   ```

   或从 GitHub 安装：

   ```bash
   dsh plugin --profile desktop add https://github.com/SShiRkiT/dsh-orchestrator
   ```

3. 安装或更新完成后，完全退出并重启 DSH，使前后端插件重新加载。
